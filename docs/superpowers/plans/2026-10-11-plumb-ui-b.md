# plumb UI, part B: window, input and scan wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make plumb usable: a Win32 window that shows the drive picker, scans a clicked drive with `scan_auto` on a worker thread, and shows the tree with mouse, keyboard, sorting, scrollbar and a context menu.

**Architecture:** `app` holds all interaction state and turns `Input`s into `Effect`s with no Win32 types (fully unit-tested). `drives` lists drive letters with free space. `window` owns the HWND, a flip-model swapchain on the adapter that drives the window's monitor, translates messages into `Input`s, runs the scan thread (it reports through a channel plus one posted message; a 100 ms timer runs only while scanning), and rebuilds the device on loss. `plumb --selftest` runs the whole stack hidden, including a real scan of a temp directory, and is the automated check.

**Tech Stack:** Rust nightly (edition 2024), `windows` 0.62, `plumb-core`, `plumb-scan`.

**Spec:** `docs/superpowers/specs/2026-10-11-plumb-disk-design.md` (sections "Window and rendering", "Layout", "Tree view", "Choosing and failing").

**Prerequisite:** Plan 3a executed (`crates/plumb` has `fmt`, `layout`, `gfx`, `draw`, `tests/render.rs`).

## Global Constraints

- "One top-level Win32 window, per-monitor-v2 DPI aware, light or dark to match the system. Everything inside is custom-drawn; there are no child controls."
- "Adapter: the GPU that owns the window's monitor (found via DXGI), logged at startup with its name and backend."
- "On `DXGI_ERROR_DEVICE_REMOVED` (e.g. eGPU unplugged), recreate the device and swapchain and repaint."
- "Redraw only on input, resize, or scan progress (throttled to 10 Hz). No timers or animation while idle."
- Mouse: wheel, drag a drawn scrollbar, click to select, double-click to expand. Keyboard: arrows, Left/Right, Home/End, PageUp/PageDown. Context menu: Reveal in Explorer, Copy path, Properties.
- The manifest stays the default `asInvoker`; elevation is the user's choice (Run as administrator). DPI awareness is set in code, so no manifest file is needed.
- Tests must not show a window or steal focus; the GPU-using selftest is `#[ignore]`d and opt-in.
- Never let a python process read stdin. Use the Write/Edit tools for files.

//! Window-independent application state: what is selected, scrolled and scanning, and how
//! input changes it. No Win32 types, so the whole interaction model tests anywhere.
use crate::draw::{Chip, Scene, Theme, View};
use crate::fmt;
use crate::layout::{Hit, Layout};
use plumb_core::rows::{Key, RowModel, SortKey};
use plumb_core::{NodeId, Tree};

#[derive(Clone, Debug, PartialEq)]
pub struct DriveInfo {
    pub letter: char,
    pub total: u64,
    pub free: u64,
}

pub enum Scan {
    Idle,
    Running { drive: usize, dirs: u64, files: u64, bytes: u64 },
    Failed(String),
}

pub enum Input {
    Click(f32, f32),
    DoubleClick(f32, f32),
    RightClick(f32, f32),
    /// Rows to scroll; positive is down.
    Wheel(i32),
    Key(Key),
    /// Mouse moved with the left button held, at this y.
    Drag(f32),
    Release,
    Resize(f32, f32),
}

#[derive(Debug, PartialEq)]
pub enum Effect {
    None,
    /// Start scanning the drive at this index.
    Scan(usize),
    /// Show the context menu for this node.
    Menu(NodeId),
}

pub struct App {
    pub layout: Layout,
    pub drives: Vec<DriveInfo>,
    pub active: Option<usize>,
    pub tree: Option<Tree>,
    pub model: Option<RowModel>,
    pub scroll: usize,
    pub scan: Scan,
    /// One line about the last finished scan (scanner, time, counts); empty before any.
    pub summary: String,
    pub adapter: String,
    sort: (SortKey, bool),
    /// While dragging the scrollbar thumb: distance from the thumb's top to the grab point.
    grab: Option<f32>,
}

impl App {
    pub fn new(layout: Layout, drives: Vec<DriveInfo>, adapter: String) -> Self {
        Self {
            layout, drives, adapter, active: None, tree: None, model: None, scroll: 0,
            scan: Scan::Idle, summary: String::new(), sort: (SortKey::Size, true), grab: None,
        }
    }

    pub fn begin_scan(&mut self, drive: usize) {
        self.active = Some(drive);
        self.tree = None;
        self.model = None;
        self.scroll = 0;
        self.summary.clear();
        self.scan = Scan::Running { drive, dirs: 0, files: 0, bytes: 0 };
    }

    pub fn progress(&mut self, d: u64, f: u64, b: u64) {
        if let Scan::Running { dirs, files, bytes, .. } = &mut self.scan {
            (*dirs, *files, *bytes) = (d, f, b);
        }
    }

    /// Installs a finished tree. The root is expanded and selected so there is something to see.
    pub fn finish_scan(&mut self, tree: Tree, summary: String) {
        let mut model = RowModel::new(&tree);
        model.set_sort(&tree, self.sort.0, self.sort.1);
        if let Some(r) = model.rows().first().map(|r| r.id) {
            model.expand(&tree, r);
            model.select(r);
        }
        self.tree = Some(tree);
        self.model = Some(model);
        self.scroll = 0;
        self.summary = summary;
        self.scan = Scan::Idle;
    }

    pub fn fail_scan(&mut self, msg: String) {
        self.scan = Scan::Failed(msg);
    }

    fn total_rows(&self) -> usize {
        self.model.as_ref().map_or(0, |m| m.rows().len())
    }

    fn max_scroll(&self) -> usize {
        self.total_rows().saturating_sub(self.layout.rows_visible())
    }

    fn set_scroll(&mut self, s: usize) {
        self.scroll = s.min(self.max_scroll());
    }

    fn row_at(&self, i: usize) -> Option<NodeId> {
        self.model.as_ref()?.rows().get(self.scroll + i).map(|r| r.id)
    }

    pub fn handle(&mut self, input: Input) -> Effect {
        match input {
            Input::Resize(w, h) => {
                self.layout = Layout::new(w, h);
                self.set_scroll(self.scroll);
            }
            Input::Wheel(rows) => self.set_scroll((self.scroll as i64 + rows as i64).max(0) as usize),
            Input::Key(k) => {
                if let (Some(t), Some(m)) = (&self.tree, &mut self.model) {
                    m.handle_key(t, k, self.layout.rows_visible().max(1));
                    let s = m.scroll_to_selected(self.scroll, self.layout.rows_visible());
                    self.set_scroll(s);
                }
            }
            Input::Click(x, y) => return self.click(x, y),
            Input::DoubleClick(x, y) => {
                if let Hit::Row(i) = self.layout.hit(x, y, self.drives.len()) {
                    if let (Some(id), Some(t), Some(m)) = (self.row_at(i), &self.tree, &mut self.model) {
                        m.select(id);
                        m.toggle(t, id);
                        self.set_scroll(self.scroll);
                    }
                }
            }
            Input::RightClick(x, y) => {
                if let Hit::Row(i) = self.layout.hit(x, y, self.drives.len()) {
                    if let (Some(id), Some(m)) = (self.row_at(i), &mut self.model) {
                        m.select(id);
                        return Effect::Menu(id);
                    }
                }
            }
            Input::Drag(y) => {
                if let Some(g) = self.grab {
                    let s = self.layout.scroll_for_thumb_y(self.total_rows(), y - g);
                    self.set_scroll(s);
                }
            }
            Input::Release => self.grab = None,
        }
        Effect::None
    }

    fn click(&mut self, x: f32, y: f32) -> Effect {
        match self.layout.hit(x, y, self.drives.len()) {
            Hit::Chip(i) if !matches!(self.scan, Scan::Running { .. }) => return Effect::Scan(i),
            Hit::Header(c) => {
                let key = [SortKey::Name, SortKey::Size, SortKey::Size, SortKey::Items][c];
                let desc = if self.sort.0 == key { !self.sort.1 } else { key != SortKey::Name };
                self.sort = (key, desc);
                if let (Some(t), Some(m)) = (&self.tree, &mut self.model) {
                    m.set_sort(t, key, desc);
                    self.scroll = 0;
                }
            }
            Hit::Row(i) => {
                if let (Some(id), Some(m)) = (self.row_at(i), &mut self.model) {
                    m.select(id);
                }
            }
            Hit::Scrollbar => {
                let total = self.total_rows();
                match self.layout.thumb(total, self.scroll) {
                    Some(t) if y >= t.y && y < t.y + t.h => self.grab = Some(y - t.y),
                    Some(t) => {
                        let page = self.layout.rows_visible().max(1);
                        self.set_scroll(if y < t.y { self.scroll.saturating_sub(page) } else { self.scroll + page });
                    }
                    None => {}
                }
            }
            _ => {}
        }
        Effect::None
    }

    pub fn chips(&self) -> Vec<Chip> {
        self.drives
            .iter()
            .map(|d| Chip {
                label: format!("{}:  {} free", d.letter, fmt::size(d.free)),
                used: 1.0 - fmt::fraction(d.free, d.total),
            })
            .collect()
    }

    fn message(&self) -> String {
        match &self.scan {
            Scan::Idle => "Select a drive above to scan it.".into(),
            Scan::Running { drive, dirs, files, bytes } => format!(
                "Scanning {}:  {} folders, {} files, {}",
                self.drives[*drive].letter, fmt::count(*dirs), fmt::count(*files), fmt::size(*bytes)
            ),
            Scan::Failed(m) => format!("Scan failed: {m}"),
        }
    }

    fn status(&self) -> String {
        let head = if self.summary.is_empty() { "plumb" } else { &self.summary };
        format!("{head}   |   {}", self.adapter)
    }

    /// Builds the scene for `dark` and passes it to `f`; the scene borrows locals made here.
    pub fn with_scene<R>(&self, dark: bool, f: impl FnOnce(&Scene) -> R) -> R {
        let chips = self.chips();
        let (message, status) = (self.message(), self.status());
        let view = match (&self.tree, &self.model) {
            (Some(tree), Some(model)) => Some(View { tree, model, scroll: self.scroll }),
            _ => None,
        };
        f(&Scene {
            layout: self.layout,
            theme: Theme::new(dark),
            chips: &chips,
            active_chip: self.active,
            view,
            message: &message,
            status: &status,
        })
    }
}

//! Drive enumeration for the picker.
use crate::app::DriveInfo;
use windows::Win32::Storage::FileSystem::{
    GetDiskFreeSpaceExW, GetDriveTypeW, GetLogicalDrives,
};
use windows::Win32::System::WindowsProgramming::{DRIVE_FIXED, DRIVE_REMOTE, DRIVE_REMOVABLE};
use windows::core::PCWSTR;

/// Fixed, removable and network drives that report a size, in letter order.
pub fn list() -> Vec<DriveInfo> {
    let mask = unsafe { GetLogicalDrives() };
    (0..26u32)
        .filter(|i| mask >> i & 1 == 1)
        .filter_map(|i| {
            let letter = (b'A' + i as u8) as char;
            let root: Vec<u16> = format!("{letter}:\\").encode_utf16().chain([0]).collect();
            let root = PCWSTR(root.as_ptr());
            let kind = unsafe { GetDriveTypeW(root) };
            if ![DRIVE_FIXED, DRIVE_REMOVABLE, DRIVE_REMOTE].contains(&kind) {
                return None;
            }
            let (mut free, mut total) = (0u64, 0u64);
            unsafe { GetDiskFreeSpaceExW(root, Some(&mut free), Some(&mut total), None) }.ok()?;
            (total > 0).then_some(DriveInfo { letter, total, free })
        })
        .collect()
}

    hwnd: HWND,
    app: App,
    gfx: Gfx,
    painter: Painter,
    swap: IDXGISwapChain1,
    target: Option<ID2D1Bitmap1>,
    dpi: f32,
    dark: bool,
    progress: Arc<Progress>,
    rx: Option<Receiver<ScanResult>>,
}

thread_local! {
    static STATE: RefCell<Option<Win>> = const { RefCell::new(None) };
}

/// Runs `f` on the window state. Returns `None` if there is no state yet or it is already
/// borrowed (a message arrived while we were inside a call such as `TrackPopupMenu`).
fn with<R>(f: impl FnOnce(&mut Win) -> R) -> Option<R> {
    STATE.with(|s| s.try_borrow_mut().ok().and_then(|mut s| s.as_mut().map(f)))
}

fn dark_mode() -> bool {
    let mut v = 1u32;
    let mut n = 4u32;
    let r = unsafe {
        RegGetValueW(
            HKEY_CURRENT_USER,
            w!("Software\\Microsoft\\Windows\\CurrentVersion\\Themes\\Personalize"),
            w!("AppsUseLightTheme"),
            RRF_RT_REG_DWORD,
            None,
            Some(&mut v as *mut u32 as *mut _),
            Some(&mut n),
        )
    };
    r.is_ok() && v == 0
}

/// The adapter that drives the monitor `hwnd` is on, so frames never cross adapters.
fn adapter_for(hwnd: HWND) -> Option<IDXGIAdapter> {
    let mon = unsafe { MonitorFromWindow(hwnd, MONITOR_DEFAULTTONEAREST) };
    let factory: IDXGIFactory1 = unsafe { CreateDXGIFactory1() }.ok()?;
    for i in 0.. {
        let adapter = unsafe { factory.EnumAdapters1(i) }.ok()?;
        for j in 0.. {
            let Ok(out) = (unsafe { adapter.EnumOutputs(j) }) else { break };
            if unsafe { out.GetDesc() }.is_ok_and(|d| d.Monitor == mon) {
                return adapter.cast().ok();
            }
        }
    }
    None
}

fn client_px(hwnd: HWND) -> (u32, u32) {
    let mut r = RECT::default();
    let _ = unsafe { GetClientRect(hwnd, &mut r) };
    ((r.right - r.left).max(1) as u32, (r.bottom - r.top).max(1) as u32)
}

fn make_swapchain(gfx: &Gfx, hwnd: HWND) -> Result<IDXGISwapChain1> {
    let (width, height) = client_px(hwnd);
    let dxgi: IDXGIDevice = gfx.d3d.cast()?;
    let factory: IDXGIFactory2 = unsafe { dxgi.GetAdapter()?.GetParent()? };
    let desc = DXGI_SWAP_CHAIN_DESC1 {
        Width: width,
        Height: height,
        Format: DXGI_FORMAT_B8G8R8A8_UNORM,
        Stereo: BOOL(0),
        SampleDesc: DXGI_SAMPLE_DESC { Count: 1, Quality: 0 },
        BufferUsage: DXGI_USAGE_RENDER_TARGET_OUTPUT,
        BufferCount: 2,
        Scaling: DXGI_SCALING_NONE,
        SwapEffect: DXGI_SWAP_EFFECT_FLIP_DISCARD,
        AlphaMode: DXGI_ALPHA_MODE_IGNORE,
        Flags: 0,
    };
    unsafe { factory.CreateSwapChainForHwnd(&gfx.d3d, hwnd, &desc, None, None) }
}

impl Win {
    fn new(hwnd: HWND, drives: Vec<DriveInfo>) -> Result<Self> {
        let gfx = Gfx::hardware(adapter_for(hwnd).as_ref())?;
        let swap = make_swapchain(&gfx, hwnd)?;
        let painter = Painter::new(&gfx)?;
        let dpi = unsafe { GetDpiForWindow(hwnd) } as f32;
        let (pw, ph) = client_px(hwnd);
        let layout = Layout::new(pw as f32 * 96.0 / dpi, ph as f32 * 96.0 / dpi);
        let app = App::new(layout, drives, gfx.adapter.clone());
        let dark = dark_mode();
        let win = Self { hwnd, app, gfx, painter, swap, target: None, dpi, dark, progress: Arc::default(), rx: None };
        win.apply_title_theme();
        Ok(win)
    }

    fn apply_title_theme(&self) {
        let v = BOOL::from(self.dark);
        let _ = unsafe {
            DwmSetWindowAttribute(self.hwnd, DWMWA_USE_IMMERSIVE_DARK_MODE, &v as *const _ as *const _, 4)
        };
    }

    fn target(&mut self) -> Result<ID2D1Bitmap1> {
        if let Some(t) = &self.target {
            return Ok(t.clone());
        }
        let surface: IDXGISurface = unsafe { self.swap.GetBuffer(0)? };
        let props = D2D1_BITMAP_PROPERTIES1 {
            pixelFormat: D2D1_PIXEL_FORMAT { format: DXGI_FORMAT_B8G8R8A8_UNORM, alphaMode: D2D1_ALPHA_MODE_IGNORE },
            dpiX: 96.0,
            dpiY: 96.0,
            bitmapOptions: D2D1_BITMAP_OPTIONS_TARGET | D2D1_BITMAP_OPTIONS_CANNOT_DRAW,
            colorContext: std::mem::ManuallyDrop::new(None),
        };
        let t = unsafe { self.gfx.d2d.CreateBitmapFromDxgiSurface(&surface, Some(&props))? };
        self.target = Some(t.clone());
        Ok(t)
    }

    /// Draws and presents one frame. A lost device is rebuilt and the frame drawn again.
    fn render(&mut self) {
        for attempt in 0..2 {
            match self.try_render() {
                Ok(()) => return,
                Err(e) if attempt == 0 => {
                    eprintln!("plumb: render failed ({e}); recreating the device");
                    if let Err(e) = self.recreate_device() {
                        eprintln!("plumb: device recreation failed: {e}");
                        return;
                    }
                }
                Err(e) => eprintln!("plumb: render failed again: {e}"),
            }
        }
    }

    fn try_render(&mut self) -> Result<()> {
        let target = self.target()?;
        self.app.with_scene(self.dark, |s| self.painter.paint(&self.gfx, &target, self.dpi, s))?;
        let hr = unsafe { self.swap.Present(1, windows::Win32::Graphics::Dxgi::DXGI_PRESENT(0)) };
        if hr == DXGI_ERROR_DEVICE_REMOVED || hr == DXGI_ERROR_DEVICE_RESET {
            return Err(hr.into());
        }
        hr.ok()
    }

    fn recreate_device(&mut self) -> Result<()> {
        self.target = None;
        let gfx = Gfx::hardware(adapter_for(self.hwnd).as_ref())?;
        self.swap = make_swapchain(&gfx, self.hwnd)?;
        self.painter = Painter::new(&gfx)?;
        self.app.adapter = gfx.adapter.clone();
        self.gfx = gfx;
        Ok(())
    }

    fn resize(&mut self) {
        self.target = None;
        let (w, h) = client_px(self.hwnd);
        let _ = unsafe {
            self.swap.ResizeBuffers(0, w, h, DXGI_FORMAT_B8G8R8A8_UNORM, DXGI_SWAP_CHAIN_FLAG(0))
        };
        self.app.handle(Input::Resize(w as f32 * 96.0 / self.dpi, h as f32 * 96.0 / self.dpi));
    }

    fn dip(&self, lparam: LPARAM) -> (f32, f32) {
        let x = (lparam.0 & 0xffff) as i16 as f32;
        let y = ((lparam.0 >> 16) & 0xffff) as i16 as f32;
        (x * 96.0 / self.dpi, y * 96.0 / self.dpi)
    }

    fn invalidate(&self) {
        let _ = unsafe { InvalidateRect(Some(self.hwnd), None, false) };
    }

    fn start_scan(&mut self, drive: usize) {
        let root = format!("{}:\\", self.app.drives[drive].letter);
        self.spawn_scan(drive, root);
    }

    fn spawn_scan(&mut self, drive: usize, root: String) {
        self.app.begin_scan(drive);
        self.progress = Arc::default();
        let progress = self.progress.clone();
        let (tx, rx) = channel();
        self.rx = Some(rx);
        let hwnd = self.hwnd.0 as isize;
        std::thread::spawn(move || {
            let t0 = Instant::now();
            let run = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
                let mut b = TreeBuilder::new();
                let report = scan_auto(Path::new(&root), &mut b, &progress).map_err(|e| match e {
                    ScanError::Root(e) => e.to_string(),
                    ScanError::Mft(m) => m,
                })?;
                let tree = b.finish().map_err(|e| format!("{e:?}"))?;
                Ok((tree, report, t0.elapsed()))
            }));
            let msg = run.unwrap_or_else(|_| Err("the scanner panicked".to_string()));
            let _ = tx.send(msg);
            let _ = unsafe { PostMessageW(Some(HWND(hwnd as *mut _)), WM_SCAN_DONE, WPARAM(0), LPARAM(0)) };
        });
        unsafe { SetTimer(Some(self.hwnd), TIMER_PROGRESS, 100, None) };
        self.invalidate();
    }

    fn poll_progress(&mut self) {
        let (d, f, b) = self.progress.snapshot();
        self.app.progress(d, f, b);
        self.invalidate();
    }

    fn scan_done(&mut self) {
        let Some(rx) = &self.rx else { return };
        let Ok(msg) = rx.try_recv() else { return };
        self.rx = None;
        let _ = unsafe { KillTimer(Some(self.hwnd), TIMER_PROGRESS) };
        match msg {
            Ok((tree, report, elapsed)) => {
                let files = tree.subtree_files[NodeId(0)] as u64;
                let s = summary(report.used, files, elapsed, report.mft.as_ref().map(|m| m.0.corrupt), report.note.as_deref());
                self.app.finish_scan(tree, s);
            }
            Err(e) => self.app.fail_scan(e),
        }
        self.invalidate();
    }

    fn selected_path(&self) -> Option<String> {
        let id = self.app.model.as_ref()?.selected()?;
        Some(display_path(&self.app.tree.as_ref()?.path(id)))
    }
}

/// "C:" is the drive's root node; shell calls need "C:\".
pub fn display_path(p: &str) -> String {
    if p.ends_with(':') { format!("{p}\\") } else { p.to_string() }
}

pub fn summary(used: Used, files: u64, elapsed: Duration, corrupt: Option<u64>, note: Option<&str>) -> String {
    let scanner = match used {
        Used::Mft => "MFT scan",
        Used::Walk => "Directory walk",
    };
    let mut s = format!("{scanner}: {} files in {:.1}s", crate::fmt::count(files), elapsed.as_secs_f64());
    if let Some(c) = corrupt.filter(|&c| c > 0) {
        s.push_str(&format!(", {c} records skipped"));
    }
    if let Some(n) = note {
        s.push_str(&format!(" ({n})"));
    }
    s
}

fn wide(s: &str) -> Vec<u16> {
    s.encode_utf16().chain([0]).collect()
}

fn copy_to_clipboard(hwnd: HWND, text: &str) {
    let u = wide(text);
    unsafe {
        if OpenClipboard(Some(hwnd)).is_err() {
            return;
        }
        let _ = EmptyClipboard();
        if let Ok(h) = GlobalAlloc(GMEM_MOVEABLE, u.len() * 2) {
            let p = GlobalLock(h) as *mut u16;
            if !p.is_null() {
                std::ptr::copy_nonoverlapping(u.as_ptr(), p, u.len());
                let _ = GlobalUnlock(h);
                let _ = SetClipboardData(13, Some(HANDLE(h.0))); // CF_UNICODETEXT
            }
        }
        let _ = CloseClipboard();
    }
}

fn reveal(path: &str) {
    let args = wide(&format!("/select,\"{path}\""));
    unsafe { ShellExecuteW(None, w!("open"), w!("explorer.exe"), PCWSTR(args.as_ptr()), PCWSTR::null(), SW_SHOWNORMAL) };
}

fn properties(path: &str) {
    let p = wide(path);
    let mut info = SHELLEXECUTEINFOW {
        cbSize: std::mem::size_of::<SHELLEXECUTEINFOW>() as u32,
        fMask: SEE_MASK_INVOKEIDLIST,
        lpVerb: w!("properties"),
        lpFile: PCWSTR(p.as_ptr()),
        nShow: SW_SHOW.0,
        ..Default::default()
    };
    let _ = unsafe { ShellExecuteExW(&mut info) };
}

/// Shows the context menu at the cursor and runs the chosen command. Called with no borrow held,
/// because `TrackPopupMenu` runs its own message loop.
fn context_menu(hwnd: HWND, path: String, at: (i32, i32)) {
    unsafe {
        let Ok(menu) = CreatePopupMenu() else { return };
        let _ = AppendMenuW(menu, MF_STRING, CMD_REVEAL, w!("Reveal in Explorer"));
        let _ = AppendMenuW(menu, MF_STRING, CMD_COPY, w!("Copy path"));
        let _ = AppendMenuW(menu, MF_STRING, CMD_PROPS, w!("Properties"));
        let mut pt = POINT { x: at.0, y: at.1 };
        let _ = ClientToScreen(hwnd, &mut pt);
        let cmd = TrackPopupMenu(menu, TPM_RETURNCMD | TPM_RIGHTBUTTON, pt.x, pt.y, Some(0), hwnd, None);
        let _ = DestroyMenu(menu);
        match cmd.0 as usize {
            CMD_REVEAL => reveal(&path),
            CMD_COPY => copy_to_clipboard(hwnd, &path),
            CMD_PROPS => properties(&path),
            _ => {}
        }
    }
}

fn effect(hwnd: HWND, e: Effect, at: (i32, i32)) {
    match e {
        Effect::None => {}
        Effect::Scan(i) => {
            with(|w| w.start_scan(i));
        }
        Effect::Menu(id) => {
            let path = with(|w| w.app.tree.as_ref().map(|t| display_path(&t.path(id)))).flatten();
            if let Some(p) = path {
                context_menu(hwnd, p, at);
            }
        }
    }
}

fn pos(l: LPARAM) -> (i32, i32) {
    ((l.0 & 0xffff) as i16 as i32, ((l.0 >> 16) & 0xffff) as i16 as i32)
}

/// Sends `input` to the app, then runs any effect and repaints.
fn dispatch(hwnd: HWND, l: LPARAM, make: impl FnOnce(f32, f32) -> Input) {
    let Some((e, _)) = with(|w| {
        let (x, y) = w.dip(l);
        let e = w.app.handle(make(x, y));
        w.invalidate();
        (e, ())
    }) else {
        return;
    };
    effect(hwnd, e, pos(l));
}

fn key_of(vk: u16) -> Option<Key> {
    Some(match vk {
        x if x == VK_UP.0 => Key::Up,
        x if x == VK_DOWN.0 => Key::Down,
        x if x == VK_LEFT.0 => Key::Left,
        x if x == VK_RIGHT.0 => Key::Right,
        x if x == VK_PRIOR.0 => Key::PageUp,
        x if x == VK_NEXT.0 => Key::PageDown,
        x if x == VK_HOME.0 => Key::Home,
        x if x == VK_END.0 => Key::End,
        _ => return None,
    })
}

extern "system" fn wndproc(hwnd: HWND, msg: u32, wp: WPARAM, lp: LPARAM) -> LRESULT {
    match msg {
        WM_PAINT => {
            let _ = unsafe { ValidateRect(Some(hwnd), None) };
            with(|w| w.render());
            LRESULT(0)
        }
        WM_ERASEBKGND => LRESULT(1),
        WM_SIZE => {
            if wp.0 != SIZE_MINIMIZED as usize {
                with(|w| {
                    w.resize();
                    w.invalidate();
                });
            }
            LRESULT(0)
        }
        WM_DPICHANGED => {
            let r = unsafe { &*(lp.0 as *const RECT) };
            with(|w| w.dpi = (wp.0 & 0xffff) as f32);
            let _ = unsafe {
                SetWindowPos(hwnd, None, r.left, r.top, r.right - r.left, r.bottom - r.top, SWP_NOZORDER | SWP_NOACTIVATE)
            };
            LRESULT(0)
        }
        WM_LBUTTONDOWN => {
            unsafe { SetCapture(hwnd) };
            dispatch(hwnd, lp, Input::Click);
            LRESULT(0)
        }
        WM_LBUTTONDBLCLK => {
            dispatch(hwnd, lp, Input::DoubleClick);
            LRESULT(0)
        }
        WM_LBUTTONUP => {
            let _ = unsafe { ReleaseCapture() };
            dispatch(hwnd, lp, |_, _| Input::Release);
            LRESULT(0)
        }
        WM_RBUTTONUP => {
            dispatch(hwnd, lp, Input::RightClick);
            LRESULT(0)
        }
        WM_MOUSEMOVE => {
            if wp.0 & 1 != 0 {
                dispatch(hwnd, lp, |_, y| Input::Drag(y));
            }
            LRESULT(0)
        }
        WM_MOUSEWHEEL => {
            let delta = (wp.0 >> 16) as i16 as i32;
            with(|w| {
                w.app.handle(Input::Wheel(-delta / 120 * 3));
                w.invalidate();
            });
            LRESULT(0)
        }
        WM_KEYDOWN => {
            let ctrl = unsafe { GetKeyState(VK_CONTROL.0 as i32) } < 0;
            if ctrl && wp.0 == 'C' as usize {
                if let Some(Some(p)) = with(|w| w.selected_path()) {
                    copy_to_clipboard(hwnd, &p);
                }
            } else if let Some(k) = key_of(wp.0 as u16) {
                with(|w| {
                    w.app.handle(Input::Key(k));
                    w.invalidate();
                });
            }
            LRESULT(0)
        }
        WM_TIMER if wp.0 == TIMER_PROGRESS => {
            with(|w| w.poll_progress());
            LRESULT(0)
        }
        WM_SCAN_DONE => {
            with(|w| w.scan_done());
            LRESULT(0)
        }
        WM_SETTINGCHANGE => {
            with(|w| {
                let dark = dark_mode();
                if dark != w.dark {
                    w.dark = dark;
                    w.apply_title_theme();
                    w.invalidate();
                }
            });
            unsafe { DefWindowProcW(hwnd, msg, wp, lp) }
        }
        WM_DESTROY => {
            unsafe { PostQuitMessage(0) };
            LRESULT(0)
        }
        _ => unsafe { DefWindowProcW(hwnd, msg, wp, lp) },
    }
}

fn create_window(visible: bool) -> Result<HWND> {
    unsafe {
        let _ = SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2);
        let inst: HMODULE = GetModuleHandleW(None)?;
        let class = w!("PlumbWindow");
        let wc = WNDCLASSEXW {
            cbSize: std::mem::size_of::<WNDCLASSEXW>() as u32,
            style: CS_DBLCLKS,
            lpfnWndProc: Some(wndproc),
            hInstance: inst.into(),
            hCursor: LoadCursorW(None, IDC_ARROW)?,
            lpszClassName: class,
            ..Default::default()
        };
        RegisterClassExW(&wc);
        let hwnd = CreateWindowExW(
            WINDOW_EX_STYLE(0), class, w!("plumb"), WS_OVERLAPPEDWINDOW,
            CW_USEDEFAULT, CW_USEDEFAULT, 1100, 760, None, None, Some(inst.into()), None,
        )?;
        // Scale the default size once the window's monitor DPI is known.
        let dpi = GetDpiForWindow(hwnd);
        let _ = SetWindowPos(hwnd, None, 0, 0, (1100 * dpi / 96) as i32, (760 * dpi / 96) as i32, SWP_NOMOVE | SWP_NOZORDER | SWP_NOACTIVATE);
        if visible {
            let _ = ShowWindow(hwnd, SW_SHOW);
        }
        Ok(hwnd)
    }
}

/// Runs the app until the window closes.
pub fn run() -> Result<()> {
    let hwnd = create_window(true)?;
    let win = Win::new(hwnd, crate::drives::list())?;
    eprintln!("plumb: {}", win.gfx.adapter);
    STATE.with(|s| *s.borrow_mut() = Some(win));
    with(|w| w.invalidate());
    let mut msg = MSG::default();
    unsafe {
        while GetMessageW(&mut msg, None, 0, 0).as_bool() {
            let _ = TranslateMessage(&msg);
            DispatchMessageW(&msg);
        }
    }
    STATE.with(|s| *s.borrow_mut() = None);
    Ok(())
}

/// Builds the window hidden, scans a small temp directory on a worker thread through the real
/// message loop and swapchain, and returns "adapter; summary". Never shows a window.
pub fn selftest() -> Result<String> {
    let dir = std::env::temp_dir().join(format!("plumb-selftest-{}", std::process::id()));
    let _ = std::fs::remove_dir_all(&dir);
    std::fs::create_dir_all(dir.join("sub")).ok();
    std::fs::write(dir.join("sub").join("f.bin"), vec![1u8; 100_000]).ok();
    let hwnd = create_window(false)?;
    let win = Win::new(hwnd, crate::drives::list())?;
    STATE.with(|s| *s.borrow_mut() = Some(win));
    with(|w| w.spawn_scan(0, dir.to_string_lossy().into_owned()));
    let deadline = Instant::now() + Duration::from_secs(30);
    let mut msg = MSG::default();
    while with(|w| w.app.tree.is_none() && !matches!(w.app.scan, crate::app::Scan::Failed(_))) == Some(true) {
        if Instant::now() > deadline {
            return Err(windows::core::Error::new(windows::Win32::Foundation::E_FAIL, "scan did not finish in 30 s"));
        }
        unsafe {
            if PeekMessageW(&mut msg, None, 0, 0, PM_REMOVE).as_bool() {
                let _ = TranslateMessage(&msg);
                DispatchMessageW(&msg);
            } else {
                std::thread::yield_now();
            }
        }
    }
    let out = with(|w| {
        w.resize();
        let sub = w.app.tree.as_ref().map(|t| t.subtree_size[NodeId(0)]);
        w.try_render().map(|_| format!("{}; {}; root {:?} bytes", w.gfx.adapter, w.app.summary, sub))
    });
    let _ = std::fs::remove_dir_all(&dir);
    unsafe { DestroyWindow(hwnd)? };
    STATE.with(|s| *s.borrow_mut() = None);
    out.expect("state present")
}
