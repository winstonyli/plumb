# One struct per side for per-view state (A1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended here: three mechanical tasks that share one rename) or superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `app::Slot` and `window::Run` each declare a view's swappable state once, and one `swap` exchanges it.

**Architecture:** `Parked` becomes `Slot` (12 fields) and `App` holds `pub slot: Slot` instead of the 12 mirrored fields. `View`'s 8 window fields become `Run`, and `Win` holds `run: Run`. Pure renames: no logic changes beyond collapsing the swap lists.

**Tech Stack:** Rust workspace, `cargo test --workspace`, perl for the mechanical rename.

**Spec:** `docs/superpowers/specs/2026-10-31-view-slot-design.md` (approved 2026-10-31, g1 + h1). Cleanup plan item A1: `docs/superpowers/plans/2026-10-31-cleanup.md`.

## Global Constraints

- Behaviour unchanged; 412 tests pass after Tasks 1 and 2; `cargo clippy --workspace --all-targets` clean.
- Not moved into `Slot`/`Run`: `held`, `map_*`, `sort`, pointer state, `borrowed`, `layout`, `views`, `active`, `marks`, `stash`, `basket_rev`, `basket_view`, `deleting`, notices, `policy`, `timers`, `clock`, `parked`, `preview_pacer`, `preview_dirty`.
- `filter.ui` stays window-owned: after swapping the whole slot, swap `filter.ui` back.
- Edit files with the Edit tool or perl `-pi` on named files; check `git diff --stat` before each commit. Never `python -` / stdin python.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Do not push, tag or bump.

## Review Focus

- A view's `filter.ui` text must not follow the view: a swap in then out leaves the typed query untouched (guard test, Task 3).
- A swap in then out of every `Slot`/`Run` field returns the original values (guard test, Task 3).
- `in_slot` still restores `active` and `borrowed` and leaves timers alone (existing tests cover it).
- A new field added to `Slot` or `Run` without updating the guard test fails to compile (destructuring without `..`).

### Task 1: `Slot` replaces `Parked` and the 12 mirrored fields on `App`

**Interfaces:** Produces `pub struct Slot` (the old `Parked`; its fields become `pub`), `App.slot: Slot`, `App::swap_slot(&mut self, p: &mut Slot)`, `App::switch_slot(&mut self, p: &mut Slot)`. `Slot` keeps `has_tree`, `tree`, `tree_mut`, `scan`.

- [ ] **Step 1: Rename and open the struct.** `Parked` becomes `Slot` everywhere: `perl -pi -e 's/\bParked\b/Slot/g' crates/plumb/src/app.rs crates/plumb/src/app/marks.rs crates/plumb/src/window.rs`. Make the 12 fields `pub` (`pub tree: Option<Tree>`, and so on). Fix the doc comment in `window.rs` that names `Parked`.
- [ ] **Step 2: Move the fields.** Delete the 12 field declarations from `struct App` (`tree`, `model`, `scroll`, `scan`, `summary`, `live`, `refreshing`, `preview_paused`, `filter`, `basket`, `proc_info`, `proc_metric`, with their doc comments) and add one field `pub slot: Slot,` documented "What swaps when another view is put on screen." In `App::new`, replace those 12 initialisers with `slot: Slot::default(),`. Check each default equals the old initialiser (`cargo build` shows a mismatch only for types without `Default`; read the old initialisers before deleting them).
- [ ] **Step 3: Rewrite the swap.** `swap_slot` becomes:

```rust
    pub fn swap_slot(&mut self, p: &mut Slot) {
        use std::mem::swap;
        swap(&mut self.slot, p);
        swap(&mut self.slot.filter.ui, &mut p.filter.ui); // the query text belongs to the window
        self.basket_rev += 1;
        let procs = self.kind() == ViewKind::Processes;
        self.layout = self.layout.with_banner(matches!(self.slot.live, LiveStatus::Stale(_))).with_cancel(self.cancelable()).with_metric(procs).with_held(procs);
        self.set_scroll(self.slot.scroll);
        self.map_reset();
    }
```


Then restore the four `impl Slot` methods (`has_tree`, `tree`, `tree_mut`, `scan`): their `self.tree` / `self.scan` are `Slot` fields and must not gain `.slot`. Confirm `swap_slot` still reads as in Step 3.
